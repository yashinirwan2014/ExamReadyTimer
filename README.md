# ExamReadyTimer

1. ExamReadyTimer is a study organiser built with Python and Tkinter.
2. It helps students plan study sessions around exam dates.
3. It includes a Pomodoro focus timer.
4. Students can track syllabus and chapter progress.
5. Study sessions can be recorded in a focus ledger.
6. A dashboard brings important study information together.
7. The project is designed for students using a desktop computer.
8. It uses Python, Tkinter and file based data handling.
9. Run instructions and feature details are available in this repository.
