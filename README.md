# ExamReadyTimer

ExamReadyTimer is a desktop study organiser I made using Python and Tkinter.
It helps students keep exam dates, study plans and chapter progress together.
The app includes an exam planner and a Pomodoro timer.
It also has a weekly timetable and a chapter tracker.
Students can record study sessions and topics for revision.
A progress view shows information based on the data entered.
The app can back up and restore its local data.
It is designed to work offline for normal use.
I built this project to practise Python, file handling and GUI development.
