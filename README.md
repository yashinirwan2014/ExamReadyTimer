# ExamReadyTimer
A study organiser built with Python and Tkinter.
It helps students plan study sessions around exam dates.
The app includes a Pomodoro focus timer.
Students can track syllabus and chapter progress.
Study sessions can be recorded in a focus ledger.
A dashboard brings key study information together.
The project is designed for student use on desktop.
Built with Python, Tkinter and file-based data handling.
Run instructions and feature details are included in this repository.
