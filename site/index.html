Download safely

Verify the file before opening it.

Every v1.4.0 release includes SHA-256 checksums for the Windows, Linux and macOS ZIP files. Compare your downloaded file's hash with the matching entry in the release's SHA256SUMS.txt file.

🔐

Check the download

On Windows, open PowerShell in the download folder and run Get-FileHash .\\ExamReadyTimer-Windows.zip -Algorithm SHA256. Compare the result with the Windows entry in SHA256SUMS.txt.

🛡️

Understand Windows warnings

The Windows build is currently unsigned, so browser or SmartScreen reputation warnings may appear. Do not disable Microsoft Defender or bypass a warning if you are unsure.

📝

Report a false positive

If Microsoft Defender incorrectly flags the official download, submit the file to Microsoft's file submission portal for review.

A matching checksum verifies file integrity only. It is not a malware scan, digital signature, Microsoft certification or guarantee that a file is harmless. The macOS package remains experimental and is not Apple-notarized.
